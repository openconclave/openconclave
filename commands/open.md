---
description: Open the OpenConclave editor in the default browser.
---

Open the URL `http://localhost:4000` in the user's default browser using the appropriate shell command for their platform:

- Windows: `start http://localhost:4000`
- macOS: `open http://localhost:4000`
- Linux: `xdg-open http://localhost:4000`

Run the command via the Bash tool. If the browser opens, say "Opened the OpenConclave editor." — nothing else. If the command fails, show the error and suggest the user open the URL manually.
